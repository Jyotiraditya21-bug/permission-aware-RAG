# Implementation tasks

Execute tasks in order; each stays within its listed scope. Proposed paths are implementation targets, not files created by this documentation task. Every function added or changed must have tests; unit tests mock LLM/embedding calls. Request approval before adding any dependency.

1. **Runtime and contracts** — Files touched: `pyproject.toml`, `src/models.py`, `src/settings.py`, `tests/test_models.py`, `tests/test_settings.py`. Done when: Python 3.12 is declared; approved dependencies support typed Pydantic v2 request, source, chunk, access, retrieval, answer, and version contracts with validation tests.
2. **Identity and ACL scope** — Files touched: `src/auth.py`, `src/acl.py`, `tests/test_auth.py`, `tests/test_acl.py`. Done when: trusted identity resolves tenant/group/source policy predicates and epochs; missing metadata denies; forged client scopes, tenant crossover, and revoked membership tests pass.
3. **Source normalization** — Files touched: `src/ingestion/sources.py`, `tests/test_sources.py`, `tests/fixtures/sources.json`. Done when: docs, tickets, and wikis normalize into source records with access metadata, change tokens, and explicit deletion/full-snapshot semantics; malformed or missing ACL records cannot publish.
4. **Change detection and chunking** — Files touched: `src/ingestion/state.py`, `src/ingestion/chunking.py`, `src/ingestion/pipeline.py`, `tests/test_ingestion.py`, `tests/test_chunking.py`. Done when: hashes/reliable modification metadata skip unchanged records, content changes generate immutable versioned chunks, ACL-only updates avoid embeddings, and deletion/idempotent retry tests pass.
5. **Filtered index adapters and publication** — Files touched: `src/indexes/base.py`, `src/indexes/lexical.py`, `src/indexes/dense.py`, `src/ingestion/publication.py`, `tests/test_indexes.py`, `tests/test_publication.py`. Done when: approved backends enforce ACL/visibility predicates inside both searches; embedding calls are mocked; staged dual-index publication, failures, revocations, and deletions cannot expose stale or partially published records.
6. **Query router and decomposition** — Files touched: `src/router.py`, `src/prompts/router.md`, `src/prompts/decompose.md`, `tests/test_router.py`. Done when: all three routes validate, decomposition is bounded and retains access scope, ambiguous/failing routing defaults to retrieval, and factual internal requests cannot bypass evidence.
7. **Hybrid retrieval and fusion** — Files touched: `src/retrieval/hybrid.py`, `src/retrieval/fusion.py`, `tests/test_hybrid.py`, `tests/test_fusion.py`. Done when: each subquery runs filtered BM25 and dense retrieval against the same published corpus version and access scope, reciprocal rank fusion deduplicates chunk IDs, and unsupported predicates fail closed before unauthorized chunks can enter candidate sets or fusion.
8. **Reranking and evidence budget** — Files touched: `src/retrieval/rerank.py`, `tests/test_rerank.py`. Done when: authorized fused candidates across subqueries are reranked into a bounded evidence set with deterministic mocked-provider tests for empty results and provider failures.
9. **Semantic answer cache** — Files touched: `src/cache.py`, `tests/test_cache.py`. Done when: embedding-similarity lookup runs after reranking with prefiltered scope/version compatibility; equivalent paraphrases can hit without exact text matching; hit evidence must remain current and in the authorized evidence set; different-intent neighbors (including changed names, dates, and negation), ACL/config/corpus changes, deletion, and TTL tests pass.
10. **Grounded generation and citations** — Files touched: `src/generation.py`, `src/citations.py`, `src/prompts/answer.md`, `tests/test_generation.py`, `tests/test_citations.py`. Done when: evidence-backed claims carry valid chunk IDs, absent/invalid grounding abstains, conversational responses contain no factual knowledge claims, and only validated grounded answers enter the cache.
11. **Async API orchestration** — Files touched: `src/api.py`, `src/service.py`, `tests/test_api.py`, `tests/test_service.py`. Done when: async FastAPI executes the documented pipeline for every route and cache outcome; trusted scope is propagated to all stages, permission epochs are rechecked before return, and failures never fall back to unfiltered retrieval.
12. **Separate metric streams** — Files touched: `src/metrics/retrieval.py`, `src/metrics/generation.py`, `src/prompts/faithfulness.md`, `tests/test_retrieval_metrics.py`, `tests/test_generation_metrics.py`. Done when: labeled recall@k/MRR and evidence-based faithfulness emit separate records linked by trace ID; cache hits, no-retrieval, missing labels, and zero permitted relevance are handled explicitly without leaking source content.
13. **Evaluation and security acceptance** — Files touched: `evals/run_evals.py`, `evals/fixtures/queries.json`, `tests/test_evals.py`, `tests/test_security.py`, `tests/test_pipeline_integration.py`. Done when: versioned judgments across source types report separate retrieval/generation results, end-to-end ACL/cache/revocation/deletion/citation gates pass, every implemented function has coverage, and baseline results support agreeing quality and similarity thresholds before release.

Each implementation task also updates `CONTEXT.md` in at most three lines. Provider choices, dependency approval, and numerical release targets remain explicit decisions; they are not assumed by this plan.
